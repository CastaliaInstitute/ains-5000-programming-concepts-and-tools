# Module 1: Getting oriented: files, accounts, and cloud work

## What you will learn

- Identify files, folders, and a [notebook](../glossary.md#notebook).
- Distinguish an account, a browser, and a [runtime](../glossary.md#runtime).
- Explain where saved work persists.

You are preparing a small [training](../glossary.md#training) event. You have a [list](../glossary.md#list) of sessions, a budget, and a document explaining the plan. A computer can help repeat calculations, but first you need to know where the instructions and saved files live. A **program** is a sequence of instructions. A **[file](../glossary.md#file)** stores information; a **[folder](../glossary.md#folder)** groups files. A browser is an application that opens web pages. [Cloud computing](../glossary.md#cloud-computing) means another computer runs the software while you interact through your browser.

A notebook combines explanations, code, and results. The notebook file is separate from the temporary computer session that executes its code. Saving a notebook preserves your edits. It does not guarantee that temporary files or [variables](../glossary.md#variable) will be available tomorrow.

## Trace where work lives

Sketch three boxes: your computer, Google Drive, and a cloud runtime. A downloaded notebook is on your computer. A [Colab](../glossary.md#colab) copy saved in Drive belongs in the Drive box. The variables created when a [cell](../glossary.md#cell) runs belong in the runtime box. Closing a tab does not automatically move work from one box to another.

Your Google account, [GitHub](../glossary.md#github) account, and Populi account identify you to different services. Being signed in to one does not grant access to another. Keep a private note of which account you use for each service, but never record passwords in notebooks.

## Practice: make a workspace map

1. Make a folder called `AINS5000` in your preferred course storage location.
2. Inside it, make `practice` and `submissions` folders.
3. Save a short text document named `workspace-map.txt` explaining where you will keep your notebook copies.
4. Record the course link and which account each tool uses. Include no passwords or private records.
5. Open the guided notebook and read its text cells before running its code.

File extensions are clues: `.md` is Markdown text; `.ipynb` is a notebook; `.csv` is a table stored as text. Renaming a file's extension does not convert its contents.
