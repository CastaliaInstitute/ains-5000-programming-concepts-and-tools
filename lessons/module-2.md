# Module 2: Create a GitHub account and find course materials

## What you will learn

- Create and recognize a [GitHub](../glossary.md#github) [username](../glossary.md#username).
- Navigate a [repository](../glossary.md#repository) and read its README.
- Distinguish reading access from classroom membership.

GitHub hosts project folders called **repositories**. A repository may contain readings, [notebooks](../glossary.md#notebook), and a history of changes. Reading a public repository usually does not require an account. Your own account is needed when an activity asks you to accept an invitation, create a repository, or save work through GitHub.

## Create and identify your account

1. Visit [GitHub signup](https://github.com/signup) and follow the service's current account-creation steps.
2. Verify your email and complete the security steps GitHub requests. Keep recovery information in your password manager.
3. Open your profile and note your **username**. The username is the account name in `github.com/USERNAME`; it is different from your display name and email address.
4. In Aurnova Populi, use your course's GitHub setup form when provided. Enter only your username. Staff will confirm the identity mapping before Classroom50 registration.
5. Accept an organization or classroom invitation only when it comes from the course route your instructor provides. A public course link is not itself an invitation.

See [GitHub's account documentation](https://docs.github.com/en/get-started/start-your-journey/creating-an-account-on-github) for current signup details. An organization is a shared administrative space; students and teachers can participate without owning that organization.

## Read a repository before changing it

Open this course's repository. Read `README.md`, then locate `intro.md`, the `lessons` [folder](../glossary.md#folder), and `notebooks`. Click a notebook to inspect it; GitHub's preview does not run its code. Use its [Colab](../glossary.md#colab) launch link when you want an executable copy.

A **[branch](../glossary.md#branch)** is a line of work within a repository. A **[commit](../glossary.md#commit)** records a checkpoint. A **fork** is a separate repository associated with another project. You will practice saving changes later; you do not need to understand every collaboration [feature](../glossary.md#feature) to read a lesson.

## Practice: a private learning journal

Create a private repository named `ains5000-practice` in your personal account if your institution permits it. Initialize it with a README. Add a short description of what you want to learn. Do not copy instructor materials or student information into it. If account creation is unavailable, record the repository navigation steps and ask course support for an approved route.

## Troubleshoot access

A 404 can mean a private repository is inaccessible, not that it was deleted. “Unauthorized” may mean the wrong GitHub account is signed in or an invitation is pending. Check the exact course link, the signed-in username, and the invitation status. Never share sign-in codes with someone offering to fix access.

**Evidence of completion:** your username and a short explanation of where you found the README and notebooks. Submit links only through the instructor's specified route; do not publish private coursework to demonstrate completion.
