# AINS5000: Programming Concepts and Tools for AI

A beginner-friendly Jupyter Book bridge into graduate AI coursework: eight lessons, eight runnable practice notebooks, eight study decks, readiness assessment, and a cross-course glossary.

- [Read the Aurnova course](https://aurnova.github.io/ains5000-course/book/intro.html)
- [Quick reference](https://aurnova.github.io/ains5000-course/book/reference.html)
- [Cross-course glossary](https://aurnova.github.io/ains5000-course/book/glossary.html)
- [Open a Codespace](https://codespaces.new/Aurnova/ains5000-course)

Install `requirements.txt`, then `make html` for the web book or `make pdf` for the linked PDF. `make site` stages both for Pages. PDF builds need a LaTeX installation. The public exercises use synthetic examples and require no secrets, external datasets, GPUs, or paid AI services.

Source is maintained by Castalia Institute; the Aurnova deployment is a delivery copy. Academic credit, formal enrollment, and grading policies are institution decisions.

## Programming readiness and concept help

New to programming or the course tools? [AINS5000: Programming Concepts and Tools for AI](https://aurnova.github.io/ains5000-course/book/intro.html) provides short lessons on GitHub accounts, Colab, Codespaces, Python concepts, saving work, and asking for help. Use its [quick reference](https://aurnova.github.io/ains5000-course/book/reference.html) to jump directly to the skill an activity requires.
