# Syllabus

## Audience and purpose

For professionals entering graduate AI study who need confidence with programming concepts and course tools. There are no programming prerequisites. Use synthetic examples and small tasks that can be checked by hand.

## Learning outcomes

By completion, you can identify where files and runtime state live; create and recognize a GitHub account; navigate a repository; open, copy, run, and save a notebook in Colab; use a prepared Codespace; explain variables, types, conditions, loops, and functions; save and share work through the assigned route; recover from common errors; and evaluate AI assistance.

## Learning sequence

| Module | Topic | Suggested effort |
| --- | --- | --- |
| 1 | Files, accounts, and cloud work | 1 hour |
| 2 | GitHub signup and course access | 1–2 hours |
| 3 | Colab notebooks and saved copies | 1–2 hours |
| 4 | Inputs, values, variables, and types | 2 hours |
| 5 | Decisions, lists, loops, and functions | 2–3 hours |
| 6 | A prepared Codespace | 1–2 hours |
| 7 | Saving, sharing, and troubleshooting | 1–2 hours |
| 8 | AI help and the readiness project | 2 hours |

The range is a planning guide, not a timed requirement. Revisit a module when a graduate activity links to it. Instructors may use the [readiness checklist](assessment.md) to identify practice needs instead of requiring repetition of skills already demonstrated.

## Learning and assessment

Practice activities are opportunities to retry. Account or tool access problems should lead to support, not an assumption that the learner cannot program. The final notebook uses a small workshop budget scenario; the [rubric](assessment.md) evaluates workflow, understandable code, checks, explanation, and responsible tool use.

Use only the accounts and submission routes your instructor approves. Follow institutional accessibility and academic-integrity policies. Text lessons and notebooks provide the same core explanations; slide decks summarize them. If a tool is inaccessible, contact course support with the specific step and request an approved alternative.
