# Readiness assessment

## Skill checks

- Identify your GitHub username and distinguish it from an email address.
- Find the course README and explain which repository contains your work.
- Save a personal Colab copy and locate it again.
- Restart a runtime and run a notebook in order.
- Explain the inputs, variables, and outputs of a short calculation.
- Change one input and predict the effect.
- Explain a condition, a loop, and a function in a small example.
- Open and stop a Codespace, or document an approved access alternative.
- Save a checkpoint and verify the stored result.
- Write a precise support request and evaluate an AI suggestion.

## Final project rubric

| Criterion | Points | Evidence |
| --- | ---: | --- |
| Workflow and saving | 20 | Correct working copy, fresh sequential run, saved artifact, assigned submission route |
| Program structure | 25 | Meaningful variables, a function, a condition, and a loop over three scenarios |
| Checking results | 25 | Predictions, one controlled change, exact-budget boundary, and a result checked by hand |
| Explanation | 20 | Labeled units, plain-language interpretation, and one limit of the estimate |
| Responsible assistance | 10 | No private data; assistant use disclosed and checked, or independent work stated |

For practice, use **ready**, **needs practice**, and **access support needed** to distinguish skill evidence from account restrictions. Instructors determine any formal pass threshold or grade. Retrying after feedback is encouraged.
