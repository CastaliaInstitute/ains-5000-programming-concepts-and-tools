# AINS5000: Programming Concepts and Tools for AI

A practical bridge for professionals beginning graduate AI coursework. No programming experience or advanced mathematics is assumed. Start with familiar tasks, make one small change at a time, and explain the result in ordinary language.

**Estimated effort:** 12–16 hours, including practice and a small readiness project. This is a preparatory learning resource; academic credit, placement, and completion requirements are set by your institution.

## Start with the tool your activity needs

Use **[Colab](glossary.md#colab)** for the guided [notebook](glossary.md#notebook) practice. Use **[GitHub](glossary.md#github)** for course access and a personal practice [repository](glossary.md#repository). Learn **[Codespaces](glossary.md#codespaces)** for activities that need a project workspace. You do not need a local [Python](glossary.md#python) installation or a paid AI assistant.

Read [the syllabus](syllabus.md), begin with [Module 1](lessons/module-1.md), or use the [quick reference](reference.md) when a graduate assignment links you here. The [glossary](glossary.md) connects plain-language definitions to lessons in this course and deeper treatment in AINS6xxx courses.

Every module has an explanation, a worked example, a guided notebook, practice, and a completion check. A notebook that runs is a starting point; being able to explain what it does is the goal.

The [AINS Student Toolkit](https://github.com/CastaliaInstitute/ains-student-toolkit) remains the shared troubleshooting reference. Course-specific access and submission rules come from your instructor.
